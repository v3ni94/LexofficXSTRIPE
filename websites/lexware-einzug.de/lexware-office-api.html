Schnittstelle

Die Lexware Office Public API und SmartEinzug

Wofür SmartEinzug die Public API von Lexware Office benötigt, welche Voraussetzungen gelten und wie der API-Schlüssel geschützt wird.

Jetzt registrieren Zur Anleitung

Was die Public API ist

Die Public API von Lexware Office ist eine Programmierschnittstelle, über die externe Anwendungen mit Erlaubnis des Nutzers auf Daten in Lexware Office zugreifen können. SmartEinzug nutzt diese Schnittstelle, um lesend auf Ihre offenen Rechnungen und die zugehörigen Kontakte zuzugreifen. Geschrieben wird in Lexware Office über diese Anbindung nicht, die Buchhaltung selbst bleibt vollständig in Lexware Office.

Wofür SmartEinzug die API benötigt

Für den SEPA-Einzug muss SmartEinzug wissen, welche Rechnungen offen oder überfällig sind und welchem Kunden sie zuzuordnen sind. Über die Public API werden diese Rechnungen und die zugehörigen Kundendaten inkrementell synchronisiert. Bereits bezahlte oder stornierte Rechnungen werden dabei erkannt und nicht fortlaufend erneut verarbeitet.

Voraussetzung: Tarif prüfen

Nach aktuellem Stand ist für die Nutzung der Public API in Lexware Office der Tarif Lexware Office XL erforderlich. Ob dies für Ihr Konto zutrifft, sollten Sie vor der Einrichtung in Ihrem Lexware-Office-Account prüfen, da sich Tarifvoraussetzungen ändern können.

Einrichtung in Kurzform

Der API-Schlüssel wird in Lexware Office unter Einstellungen, Erweiterungen, im Bereich Public API erzeugt und anschließend in SmartEinzug hinterlegt. Die vollständige Schritt-für-Schritt-Anleitung finden Sie unter Lexware Office API-Schlüssel einrichten.

Sicherheit des API-Schlüssels

Der API-Schlüssel wird nach der Eingabe serverseitig verschlüsselt gespeichert und im Klartext nicht erneut angezeigt. Weitere Angaben zum Umgang mit Zugangsdaten und zur Trennung von Mandanten finden Sie unter Sicherheit bei SmartEinzug.
